<summary><b>#1 🔴 **CRITICAL** - setState() called after await without mounted check</b> (<code>lib/screens/login_screen.dart:17-19</code>)</summary>

- **Category:** `reliability` | **Rule:** `FLUTTER-001 (Missing "mounted" Check After Async Gap)`
- **Problem:** An async gap exists between http.post and setState(). If the user navigates away before the network request finishes, calling setState will throw FlutterError and crash.
- **Why it matters:** Causes unhandled Flutter runtime exceptions in production when users pop the route quickly.

**Issue Code:**
```diff
- final response = await http.post(Uri.parse(...));
- setState(() { _isLoading = false; });
```
**Suggested Fix:**
```diff

+ if (!mounted) return;
+ setState(() { _isLoading = false; });
```
